# Fuego · web

Sitio de Fuego by Mónica Ruiz (velas artesanales, Girón, Santander). Hecho por Integria.

- Next.js (App Router) + TypeScript, GSAP y Lenis para el movimiento.
- `src/app/page.tsx` tiene el contenido, `src/components/Motion.tsx` todo el movimiento y `src/lib/catalogo.ts` los datos de muestra del catálogo.
- Venta por WhatsApp con mensaje prellenado.

```bash
npm install
npm run dev
```
